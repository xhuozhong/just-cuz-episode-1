# Reading continuity, local lettering and bounded recovery

The Q301 public re-audit found page82's Chinese narration layered over its English source, page78's upper invitation across the character hair, music playing with its toggle hidden in short landscape/immersion, and user zoom resetting on every navigation. This revision addresses those specific reading problems while retaining the 85 native source pages, accepted orbit media, six-language translations/fonts and the removed enlargement-button decision.

Page82 uses a new source-bound, transparent glyph-only erasure patch and a content-hashed lettering packet. Built-in image editing supplied the clean-plate reference; only pixels selected by the original English-ink mask are exported. The whole generated page is never used as comic artwork. Pink/yellow background remains, every native pixel outside that mask is unchanged, and characters/other panels remain native. The old packet is retained for cached readers. Page78 adds one source-SHA-bound reviewed foreground exclusion for its upper cue.

The same existing music control group moves into More when its header is hidden, preserving audio identity and state. Explicitly selected zoom is retained across page turns and by orientation; each new page starts at its reading origin, and the existing Fit action returns to fit. Short landscape reuses the existing actions in a compact side column. Grouped regions have distinct localized accessible names and existing arrow/Home interaction guidance; no new permanent toolbar or enlargement entry is added.

Current-target model transport recovery is bounded and navigation-cancelable. Temporary server/network failures may retry once; invalid data/checksums are never automatically retried. Existing original-reading fallback and manual retry remain. The implementation must pass healthy, temporary/persistent fault, terminal shared-budget and navigation-abort cases before release.

Q301's eight first-pass desktop drag failures remain recorded. A longer P1–26 sequence reproduced the same affected hosts; a trusted native dragstart from the canvas immediately preceded pointercancel. A narrowly scoped player guard prevents the browser's default drag only while that player's own orbit gesture is active. Genuine cancellation, pinch, gyro and source/ready gates remain. The same long sequence and recovery/input regressions must pass before release. Physical-phone gyroscope/speaker and every-HD-angle art certification remain outside browser-only acceptance.

Release is gated by exact component-source checks, full-book desktop/mobile verification, fault/reading-control/lettering checks and the existing protected GitHub Pages workflow. Actual-public bodies, post-deployment reading behavior and all three same-profile timing samples are recorded in external acceptance receipts after Deploy succeeds. No universal speed improvement is asserted from source size or one timing sample.
