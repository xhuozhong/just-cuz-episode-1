# Just Cuz · 三集互动漫画合集

[打开互动漫画](https://xhuozhong.github.io/just-cuz-episode-1/collection/)

包含原合集首页和三集故事，共85页。当前为持续优化的公开体验版；生成的其他视角仍可能存在人物或空间衔接瑕疵，不代表全部画面已经通过最终质量验收。

## 阅读

- 左右拖动单个画格查看不同视角，松手逐渐减速；双击或按Home还原原画。
- 单格独立操作，保持原漫画的页序和分格布局。
- 可切换中文、英文、日文、韩语、俄语、法语；品牌标题Just Cuz保留英文。
- 每集使用对应背景音乐。浏览器限制自动有声播放时，首次点击后开始，也可手动暂停。
- 先显示当前页原画和小体积全角度预览，再补充高清帧。预览可拖动后淡化加载提示，高清完成后隐藏。

原画静态阅读层、原始帧数和原有视频回退保留。生成视角属于AI辅助的环绕表现，并非可自由移动的真实三维场景。

## 发布与加载验收

合集源码及素材位于`dist/collection/`，原第一集版本仍保留在仓库中。GitHub Actions验证每个发布文件、原页和素材绑定、帧包内每帧的内容摘要及尺寸，再生成独立`_site/`发布产物。

GitHub Pages提供页面、原画、预览、文字保护图层、音乐与视频回退。高清帧包使用当前发布提交的固定GitHub raw地址，避免超过Pages的1GB站点限制；原帧包也完整保留在本仓库。没有重绘、丢帧或将未审核素材标记为合格。

在公开地址添加`?perf=1`可查看本次浏览器的加载记录，关闭参数即恢复普通界面。诊断数据只在浏览器内显示，不上传到任何分析服务。不同网络、缓存状态和设备的延迟会不同；文件压缩比例不等于实际等待时间的同比改善。

已有Cloudflare镜像仍服务旧版素材；本轮合集新镜像上传未完成，当前发布不依赖它。
