# Just Cuz · 第一集：生日派对

[打开互动漫画](https://xhuozhong.github.io/just-cuz-episode-1/)

第一集共 34 页，对应原合集 PDF 第 2–35 页；合集首页不作为故事页。38 个主画格包含 50 个可独立操作的区域。

## 阅读方式

- 左右拖动画格查看其他方向，松开后缓慢减速；不同画格互不影响。
- 双击当前画格或按 Home 回到原画；“复位本页”还原整页。
- 使用翻页按钮或简洁目录换页。支持窄屏排版。
- 背景音乐会尝试自动播放；浏览器阻止有声自动播放时，首次点击页面后开始，可用音乐按钮暂停。

静态阅读与复位展示原漫画，保留原画文字和布局。其他视角根据原画补绘并生成视频，属于生成式环绕效果，部分片段存在视角衔接变化，不代表可自由移动的真实三维场景。

## 公开版本

网站内容位于 `dist/`，无需安装依赖或构建。GitHub Actions 将该目录发布到 GitHub Pages。可通过任意本地静态服务器预览。

为减少下载体积，6,437 张交互缓存帧使用 WebP quality 84 有损压缩，保持帧数、顺序与尺寸；原漫画页面、单格原图、视频、文字保护图层与音乐保留原文件。详细检查见 [验收说明](docs/acceptance.md)。
